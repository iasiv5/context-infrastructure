# Hermes Agent(一)OpenClaw的高阶平替

# 摘要（用于分享）
最近超火的Hermes Agent体验如何？它是如何靠“自进化”疯狂圈粉的？今天手把手带安装Hermes，并接入飞书，开启定制专属Coding Agent的第一步！

---

最近，沉迷折腾各种 Agent 的圈子里，**Hermes Agent** 算是一个相当火爆的关键词。很多人把它看作是 OpenClaw 的“高阶平替”，而它最核心的优势或者说最大噱头，就是传说中的**「自进化」**能力。

这让我不禁构思了一个大胆的想法：**能不能基于这个 Harness，来定制一个专属于我自己的专业 Coding Agent？**

说干就干。今天这篇是系列的第一步，我们先不写代码，用“魔法打败魔法”，让 AI 帮我们把这个“Coding 爱马仕”请进门。

---

### 1️⃣ 第一步：一句话让 Claude Code 代劳安装

既然都是 AI 时代的程序员了，安装环境这种脏活累活，当然要交给 Claude Code（简称 CC）来干。

我直接给远程的 CC 扔了下面这段提示词，然后端起茶杯静静等待：

> **【提示词 1】**
> 帮我安装 https://github.com/NousResearch/hermes-agent
> *(注：中途记得给 CC 一些授权，并强调“完全安装”的要求)*

只要授权给够，CC 就会乖乖把依赖、环境全部搞定，极其丝滑。

---

### 2️⃣ 第二步：一条龙初始化与启动

安装完成后，就到了配置环节。这里我参考了中文的官方上手教程（*https://hermes-doc.aigc.green/getting-started/quickstart*）。

直接在终端执行初始化命令：

```bash
hermes setup
```

这是一个极其顺畅的“一条龙”配置向导。最关键的一步是**配置 LLM Provider**（大模型提供商），绑定好你的 API Key 后，就可以正式启动 Hermes 了。

---

### 3️⃣ 第三步：接入飞书，让 Agent 走出终端

一个合格的现代 Agent，不能只活在黑框框里，得能随时随地跟我们用 IM 沟通。Hermes 支持飞书远程渠道，配置起来同样简单粗暴。

在 Hermes 的交互提示框中，我丢出了第二段提示词：

> **【提示词 2】**
> 根据网页内容，帮我配置飞书远程渠道 - https://hermes-doc.aigc.green/user-guide/messaging/feishu

安装好飞书渠道后，需要启动 Gateway 来验证。
**细节体验拉满：**当我在本地 Hermes 提示框输入“启动”时，竟然发现了 CC 同款的自动补全功能，手感极佳！

配置好飞书的 `APP ID` 和 `App Secret` 之后，第一次飞书通信会要求输入配提示配对码。按照提示设置好主目录（Home Directory），依次完成配对即可。

**进阶玩法：**
当然，Hermes 也原生支持官方飞书 CLI。如果你更喜欢用官方工具，一段提示词同样能搞定：

> **【提示词 3】**
> 你去学习这个 https://github.com/larksuite/cli ，以后飞书相关的操作都通过这个 cli 来执行。

---

### 4️⃣ 第四步：换个“皮肤”，准备开干

功能跑通了，颜值也不能落下。顺手让 Hermes 帮我换了一个我最喜欢的 Skin（皮肤）。看着崭新的界面，感觉我的“Coding 爱马仕”已经初具雏形了：）

**这只是个开始，接下来的计划更加硬核：**
- 开启 Holographic 长期记忆系统
- 缩减非编程相关的冗余 Skills
- 测试将高深 Coding 任务自动委托给 Claude Code 的能力

（记得关注，下一篇我们开始正式深度定制！）

---

### 🎁 彩蛋：可怕的“自动提炼”技能

文章开头提到，Hermes 最大的噱头是**“自进化”**。到底有多夸张？

我发现，**Hermes 是真的非常非常喜欢把经验提炼成 Skills。**这根本不需要我写 Prompt 去 PUA 它，只要一个任务做完，一个封装好的 Skill 就“Duang”地一声自动落地了。

出于好奇，我问了下它今天到底“自动”生成了多少个技能。好家伙，直接拉出了这三项：

**1️⃣ hermes-custom-skin**（2 小时前创建）
- **类别**：`software-development`  |  **大小**：6.3 KB
- **场景**：帮我自定义 Hermes CLI 皮肤时，它从源码中自动分析了完整的皮肤系统并保存了经验。

**2️⃣ image-generation-and-sharing**（7.3 小时前创建）
- **类别**：`media`  |  **大小**：3.4 KB
- **场景**：之前帮我生成小狸花猫喝水照片时，它默默摸索出并固化了整个生图与分享的完整流程。

**3️⃣ wsl-sqlite-wal-fix**（9.1 小时前创建/更新）
- **类别**：`devops`  |  **大小**：1.7 KB
- **场景**：解决 WSL 环境下 SQLite 锁协议报错时，自动沉淀的排障修复经验。

不到半天时间，干完活就把流程变成可复用的工具代码。这种**“吃一堑长一智，干一票存一技”**的能力，确实让人有点两眼放光。
