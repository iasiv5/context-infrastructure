# Hermes Agent：越用越好用——因为它在给自己造Skill

### 摘要
装上 Hermes Agent 玩了三天，发现它不仅能自主摸索落地方案，还能把复杂工作流自动封装成可复用的 Skill。本文分享4个让我直呼「有点东西」的真实被秀套路，涵盖自动配字幕、大文件分块传输和人格迁移。

---

# 正文

前几天把 Hermes Agent 装上，本来只打算随便玩玩。

结果我发现这个 Agent 有一个让我非常意外的特点——**我几乎不需要教它做什么，它自己就能摸索出落地方案。**

更让我没想到的是，每次摸索完，**它还会把经验沉淀成一个可复用的 Skill（技能）**。

这篇文章，和大家分享四个这几天实操中让我觉得「有点东西」的真实例子。

---

### 01 | 定制专属二次元/狼人皮肤，拯救命令行审美疲劳

Hermes Agent 原生支持自定义 CLI 皮肤。

说实话，一开始我在心里吐槽：一个干巴巴的终端黑框框换个皮这算啥生产力？但本着来都来了的心态，我还是捏了一套**狼人主题**，又搞了一套**二次元软妹主题**。

结果终端跑起来的那一刻，嘿，真香。这就不仅仅是调个色那么简单了，更像是……**你每天面对的冰冷生产力工具，突然拥有了专属你的「人格碎片」。**对于有极客收集癖的玩家来说，这种深度定制极其上头。

这也向我证明了第一件事：**这个工具的把玩上限，比满屏幕枯燥的代码高得多。**

> 💡 **（此处需插入：狼人主题与少女主题的 CLI 终端双拼对比图，展示视觉反差效果）**

---

### 02 | 丢个外网短视频链接，下载+中文字幕一步搞定

这是目前我的高频动作。

平时在 X 或者油管上看到有意思的视频，我现在直接把链接丢给 Hermes，留下一句：*「帮我把这个视频下载下来，配上中文字幕。」*

它系统里居然自带跑这套流程的内置 Skill。**解析链接、下视频、抽音频、转录生成 SRT 字幕、最后把字幕压制进视频——这几个以前要折腾一堆 Python 脚本的繁琐步骤，它全套自动流转。**

我甚至试过让它顺便做一下中文配音。不过说实话……免费的TTS模型效果有点僵硬，像是早年间的那种机器翻译朗读，不太能听，后来我就老老实实只让它配字幕了，效果完美！؏؏☝ᖗ乛◡乛ᖘ☝؏؏。

最爽的是，做完之后我可以让它**直接通过飞书聊天窗口发给我**。不需要我自己满电脑找文件、下载、拖拽传输。从看到视频到拿到带中文字幕的版本，全程就是一句话的事儿。

---

### 03 | 特朗普观点蒸馏：跨流派的人格降维打击

这个 case 大概是我这几天遇到最赛博朋克的。

最近 Agent 圈子里很流行玩「人格蒸馏」，比如搞个资深程序员同事 Skill、可蒸馏万物的女娲 Skill 等。我顺手搞到了一个女娲系统蒸馏出来的「特朗普 Skill」，直接喂给了 Hermes。

我的要求是：*先深度分析这个 Skill 的内容、结构和优缺点，然后看看能不能改造成你自己的 Skill。*

**它真的做到了。**

它先是把整个 Trump Skill 彻底拆解了一遍——**思维框架、行为逻辑、表达风格、决策模式**，全部过了一遍。然后告诉我，哪些部分可以直接复用，哪些需要改写才能适配 Hermes 现有的架构。

最后，它真给我改造出了一个 Hermes 版本的 Trump Skill。

装上之后，我立马让它用「懂王」的视角，锐评一下最近 Anthropic 的 mythos 模型事件（那个因为能力太强被雪藏的传说模型）。

怎么说呢，**吐槽精准度相当高，逻辑自洽又好玩。**这个例子让我意识到：Hermes 绝不仅仅是个无脑执行命令的机器，**它能理解一个 Skill 的精髓，并进行跨架构的迁移和改造。**

---

### 04 | 抖音长视频的分片处理与传输

今天早上在抖音刷到一期讲 AI Agent Coding 的 20 分钟长视频，干货密度极高，必须收藏（吃灰）。

我照例顺手把链接发给 Hermes，让它下载并发给我。下载很快，但遇到了一个硬核问题：**这个视频有 160 多兆，而飞书会话中单个文件传输上限是 20MB。**

我心想这波肯定得报错宕机了，准备切回终端自己拷视频。

结果，**它自己不声不响地开启了高达 90 多次工具调用的极限操作。**

它先是自动尝试了各种网盘方案，发现没有现成的免费网盘账号可以用。接着，它自己想到了一个「分而治之」的 Geek 办法：**把视频切成 9 个小片段，每个精确控制在大约 19MB，然后全部上传到了我的飞书云盘。**

最有意思的是，传完之后它还贴心地跑来告诉我，教我怎么合并回去。只需要在终端里跑一条极其简单的 `cat` 命令，就能把这 9 个片段无损拼接回完整视频：

```bash
# 在终端中执行，将所有分片合并为一个完整视频
cat video_part_* > full_video.mp4
```

整个过程我连鼠标都没碰，就安心看着它在飞书对话框里一波接一波地疯狂折腾，汇报进度。

这事儿干完以后，**它反手就把刚才这套大文件解构传输的复杂操作，自动沉淀成了一个专门的新 Skill**。下次再碰上大文件？它默认就会这么解了。

---

### 总结一下

这四天的体验，Hermes Agent 彻底刷新了我的认知偏见：

**Agent 最好玩的不是它完美的执行力，而是它遭遇阻碍时，用你意想不到的方式跑通闭环，并把经验固化成技能卡的能力。**

上面四个例子，每一个最后都自动对应生成了一个专用的 Skill。皮肤定制有 Skill，视频下载加字幕有 Skill，懂王分身有 Skill，大文件分片传输也有 Skill。

这就是它最与众不同的地方——**我不需要满世界给它找插件，它在给自己造武器。**

模型方面，我目前给它挂载的是智谱的 GLM-5.1 和 GLM-5-turbo。对于这些探索性任务，智能水平完全够用。

至于更复杂、更重量级的工程代码任务表现怎么样……等我再重度玩几天，攒够了坑再来和大家汇报。
