前两天把 Hermes Agent 装上，本来只打算随便玩玩。
结果玩了三天，我发现这个 Agent 有一个让我意外的特点——我几乎不需要教它做什么，它自己就能摸索出落地方案。
更让我没想到的是，每次摸索完，它还会把经验沉淀成一个可复用的 Skill。
这篇文章分享四个让我觉得「有点东西」的真实例子。

---
🐺 例子一：定了两套皮肤，收藏癖满足了
Hermes Agent 支持自定义 CLI 皮肤。
说实话一开始我没太当回事，毕竟 CLI 工具换个皮肤能有什么意思？
但我还是定了一套狼人主题的，又定了一套二次元少女主题的。
结果换上之后，整个交互体验还真的不一样了。不是功能层面的提升，更像是……你每天面对的工具突然有了点个性。
对于有收集爱好的玩家来说，这个定制还挺上头的。
而且这个过程本身就说明一个问题：这个工具的可玩性比我想象的高。不是一个干巴巴的命令行工具，而是一个有点「人格」的东西。

---
🎬 例子二：丢个链接，视频 + 中文字幕全搞定
这个是我用得最多的功能。
在 X 或者 YouTube 上看到有意思的视频，我直接把链接丢给 Hermes，说：「帮我把这个视频下载下来，配上中文字幕。」
它自带做这件事的 Skill。
下载、提取音频、生成字幕文件（SRT）、烧录到视频里——整个流程全自动。
我甚至试过让它做中文配音。怎么说呢……效果有点僵硬，像是早年间的那种机器翻译朗读，不太能听。
后来我就只让它配字幕了，这个效果好得多。
最方便的是，做完之后我可以让它直接通过飞书聊天窗口发给我。不需要我自己去找文件、下载、传输。
从看到视频到拿到带中文字幕的版本，全程就一句话的事儿。

---
🇺🇸 例子三：特朗普 Skill 蒸馏，然后锐评了 DeepSeek ME
这个是我觉得最有趣的一次。
最近社区里有一些「人格蒸馏」的 Skill，比如同事 Skill、女娲 Skill。我把女娲蒸馏出来的特朗普 Skill 发给了 Hermes。
我的要求是：先深度分析这个 Skill 的内容、结构和优缺点，然后看看能不能改造成你自己的 Skill。
它真的做了。
先是把整个 Trump Skill 拆解了一遍——思维框架、行为逻辑、表达风格、决策模式，全部过一遍。
然后告诉我哪些部分可以直接复用，哪些需要改写才能适配 Hermes 的架构。
最后改造出了一个 Hermes 版本的 Trump Skill。
装上之后，我让它用懂王的视角锐评了一下最近 DeepSeek 的 ME 事件（就是那个「能力太强不愿发布给大众」的神秘模型）。
怎么说呢，吐槽精准度相当高，还挺好玩的。
这个例子让我意识到：Hermes 不只是执行命令，它能理解一个 Skill 的精髓，然后迁移和改造。

---
📦 例子四：160MB 的视频，90 多次工具调用
今天早上在抖音刷到一个讲 AI Agent Coding 的视频，20 分钟，讲得不错。
我顺手把链接发给 Hermes，让它帮忙下载并发给我。
下载很快。问题是——这个视频有 160 多兆，而飞书单个文件传输上限是 20MB。
我以为这就卡住了。
然后它开始了整整 90 多次工具调用的操作。
先试了各种网盘方案，发现没有现成的免费网盘账号可以用。
然后它自己想到了一个办法：把视频切成 9 个片段，每个大约 19MB，全部上传到我的飞书云盘。
最后还贴心地告诉我：用一条 cat 命令就能把这 9 个片段合并回完整视频。
整个过程我什么都没做，就看着它在飞书对话框里一波接一波地折腾。
而且，做完这件事之后，它又自动把整个流程沉淀成了一个 Skill——专门处理大文件分片传输的。

---
💡 最后说两句
四件事看下来，我觉得 Hermes Agent 给我最深的一个印象是：
它不只是执行你告诉它做的事，它会自己探索解决方案，甚至把解决方案变成可复用的工具。
上面四个例子，每一个最后都对应了一个专用的 Skill。皮肤定制有 Skill，视频下载 + 字幕有 Skill，特朗普人格有 Skill，大文件分片传输也有 Skill。
我不需要给它找 Skill，它在给自己造 Skill。
模型方面，我目前给它用的是智谱的 GLM-5.1 和 GLM-5-turbo。对于我安排的这些任务来说，智能完全够用。除了高峰时段偶尔卡一下，体验没什么毛病。
至于更复杂、更重量级的任务表现怎么样……等我再多玩几天再说。
