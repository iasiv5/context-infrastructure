# DeepSeek Harness 必装插件②：dsh-skins

换脸是最简单的快乐。在工具上，得换得安心。

装修系列第 2 期：dsh-skins。五款外观，凡人修仙传、天官赐福、OpenBMC、UEFI Harness，加官方本体，明暗各一份配色。

壁纸支持自定义上传，个人图库所有皮肤共用；会话框 Slogan 自己写，通透度随便调，即改即存。DSH 从此有了你的专属风格和氛围。

凡人修仙传与天官赐福是非官方粉丝作品，壁纸为 AI 生成画作；选官方，随时回家。

装法，贴给 DSH 会话里的 agent：

```text
帮我安装 DSH 皮肤插件 @iasiv5/dsh-skins：
1. 执行 dsh plugin --profile web add @iasiv5/dsh-skins；
2. 安装成功后重启 DSH Web（若由 systemd 管理，重启对应服务即可）；
3. 最后提醒我刷新页面。
若安装失败，把命令输出原样发给我，最多重试一次。
```

装了 dsh-m 的，插件市场搜 DSH Skins，一键安装。

源码：[iasiv5/dsh-skins](https://github.com/iasiv5/dsh-skins)。下一篇：better-sidebar，聊天窗口长成 IDE。
