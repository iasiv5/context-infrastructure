# 语气档案
更新：2026-11-01 · 样本 87 篇（正样本以 2026-04 后定稿为主，方法见文末）· 用途：替 iasi 写任何署名文字前先读本档，按文体套用

## 速用卡

一句话画像：工程师口吻的说理者。短段落、结论先行、断言配硬数字，「不是X，而是Y」当骨架句式，驯马和管家比喻贯穿，称「你」不称「您」，零感叹号，情绪交给「。。」「？？？」。

写作铁律（按优先级）：
1. 一段 1–3 句，重音和结论单独成段；长句铺陈后甩短句收点
2. 结论先行：敢下死结论，断言配硬数字（百分比、倍数、条数、轮数）
3. 「不是X，而是Y」是骨架级句式；关键判断句加粗（不满篇加粗）
4. 称读者「你」，讲亲历用「我」并写出坚持（「我心意已决」）；不出现「您/各位/小编/笔者/家人们」
5. 工程词族放开用：沉淀、闭环、落盘、锁死、复利、蒸馏、踩坑、翻车、兜底、收进一个入口
6. 概率说「大概率/往往/通常/保守估计」；「也许/或许/或许吧」不给自己的判断用
7. 零感叹号；省略号少用；情绪用「。。」「？？？」和反问推进（问号是高频标点）
8. 比喻成体系：驯马/缰绳/笼头、超跑当马车、管家/查岗、刹车/油门、错题本/垫脚石、把不确定性关进笼子
9. Agent、Skill、Harness、Prompt、Token、commit、ADR、Know-how 不翻译；中英之间加空格；命令和路径用反引号
10. 结尾金句对仗收束，接一个具体的评论区提问；发布文案另加源码链接和下篇预告

文体切换（写前先定文体，篇内不混用）：

| 维度 | 严谨技术文 / 发布文案 | 公众号观点 / 实战文 |
| :--- | :--- | :--- |
| 开头 | 格言式，两句内定调 | 设问、新闻由头、痛点场景 |
| 引号 | 直角「」 | 弯引号“” |
| 情绪 | 零 emoji、零网梗 | 零 emoji 装饰，网梗每篇 ≤1 个 |

## 节奏与结构
- 短段快节奏：一段 1–3 句（中位 2 句、66 字），近半段落单句成段当重音（实测 48.6%）。排比连环短句收在四字口语上（「一会儿顺序反了。/一会儿把活重做了一遍。/一会儿根本没打招呼。」）
- 小标题中位 6 个/篇。实战文用「一、二、三」中文数字或「第 N 招/第一件事/Round N」编号，流程用①②③＋箭头（① 终端打标 → ② Gateway 接管）。小标题写完整判断句而非名词短语（「真正的拉扯，不在实现，而在顺序」）；科普文小标题用口语问句（「谁躲不掉？」「得交什么卷？」）
- 结构骨架：实战文＝背景 → 编号步骤/回合 → 「后记」小节（11/17 篇有）；观点文＝「N 阶段/N 条/N 招」枚举，偏爱 3 条一组；对比配 Markdown 表格（✓/✅/❌）；块引用（>）当金句容器
- 公众号发布组件：文末附摘要（常写两版）、配图建议、备选标题、互动话题；截图占位符嵌叙述流（「> [截图：Agent 对齐意图]」）。这属于发布流程：替用户写正文时可省略，需要时先问
- 开头排序：直接断言/痛点场景 > 新闻由头（「前几天/这两天/刷到」）> 设问；爱用「短句陈述＋但/现在转折」钩子（「量子计算还没成熟，但它的威胁已经开始计时。」）；多条新闻并排砸出后接即时身体反应（「这两天我连续刷到三条消息」「我当时就愣了一下」）
- 结尾：金句对仗收束（「让大模型在天上飞，但必须用缰绳把它死死拴在地面的打卡机上。」）→ 评论区提问 → GitHub 链接自荐（iasiv5 系列，6 篇）；实战文常先坦白残留问题再收尾（「已记入 Know-how，下不为例」）
- 标题：冒号双段式为主（28/87，如「ob-harness 实战：动作＋宾语」）；「不是A，而是B」「从X到Y」直接入题；具体数字入题（「我只用了 9 条符号链接」）

## 人称与称呼
- 「你」直接对话读者，全量 904 次，设身处地假想（「你如果是甲方技术负责人，你也会怕」）
- 「我」讲亲历与坚持，747 次（「我维护的 ob-harness」「我心意已决」「我则一直坚持」）；「我们」指团队或人类（161）；「大家」偶用于分享语境，多在互动话题区；「同学」指同事或读者（「有想法的同学，评论区见」）
- 分析型深度文可通篇少人称，主语让位给机制和模型
- 从不用：您、各位、小编、笔者、朋友们、亲们、宝子、家人们（「您/笔者」仅 2026-02 两篇 AI 润色稿残留，已确认剔除）
- 给工具/AI 起拟人绰号并通篇沿用：ob=管家、Agent=爱自作主张的新助理/实习生、小黄鸭、懂王、龙虾、特工、Coding 爱马仕

## 常用词 / 不用的词
常用（工程语境自用，非管理黑话）：
- 资产/机制词族：沉淀 87 次/34 篇、闭环 62/23、复用 36/24、复利 27/10、蒸馏 27/6、落盘、锁死、收进/收拢/收口、兜底、工作流、错题本、垫脚石、心法、实战 27/18、实录
- 踩坑词族：坑 46/28、踩坑、翻车、深水区、返工、拉扯、钉死/钉住
- 加速词：直接（24 次/9 篇）、极其（不用「非常」）、硬核、绝对、干脆
- 方法论口头禅：「一次只问一个问题」/「苏格拉底心法」（4 篇复现）、「一句话总结」、置信度（high/medium/low）、冒烟测试、银弹、对齐、边界、前提
- 口语点缀，每篇 ≤1 处：说实话（12 次）、顺手/顺便/顺带、一口气、奢俭由你、坐等上菜、苦哈哈、差一点意思、抄作业、身体很诚实、来都来了、真香、拉满、东一榔头西一棒子
- 招牌句式：「不是X，而是Y」矫正式定义（骨架级，单篇可达 14 处）；「从X到Y」演进对照；顶针推理链（「可预测了才有信用，有信用了才敢把几小时编译交给它」）；「结论很直接：」「答案是：」「就干了两件事」
- 比喻库成对成体系、绑定论点：驯马/马具/缰绳/笼头（Harness 本体比喻）、超跑当马车、波音 747 买菜、Coding 爱马仕、管家/查岗/监工、刹车/油门（「前 5 步踩刹车，后 2 步才给油门」）、搬家/回家、存档/读档、峰谷电价表、把不确定性关进笼子、探路队趟水、发动机 vs 修路
- 幽默：苦味自嘲（苦哈哈等两小时 bitbake、陪聊、新手村水平、收藏吃灰）；反问推进（全量问号 236 个）；粗口自律（fucking 写成 **ing 消音，情绪顶到「血压飙升/鸡飞狗跳」为止）

不用：
- 管理黑话：赋能、抓手、颗粒度、打法、组合拳、顶层设计、降本增效、赛道。只在讽刺引用语境出现（「你的底层逻辑是什么？抓手在哪？」）
- 亲昵营销腔和客套收尾：「谢谢你看我的文章，我们下次再见」「转发三连」「给我个星标～」
- emoji 装饰（已确认零容忍；🟢🔴 这类功能符号除外）
- 「综上所述/总而言之」不用，用「一句话总结」小节替代；对冲软话不用：「也许/或许/打个不太恰当的比方/不过也要坦诚说一句」

AI 味剔除清单（样本出现过、明确不学）：极致、终极、飞轮、必杀技、刀刀见血、疯狂拆家、灵魂拷问、毒舌、永续保鲜、夯实、回拢、合流、重塑、革命性；四字格堆叠；通篇加粗；花哨小标题（「行云流水的双线操作」）；emoji 装饰；「我管这叫」「有意思的是」「值得一提的是」说明文腔；「你是否经历过」套路开头；历史大类比（19 世纪电力）；整段名词科普（已知概念直接用）；「这四步背后的意思非常清楚」式总括过渡句；半角标点混排；机械对仗每节必金句

## 判断与语气
- 结论先行，敢下死结论：「结论很直接：千万别」「这场发布会没有输家」「FDE 不是 PMF。它更像探路队。」
- 断言配硬数字背书：94.9% 缓存命中、87 倍、57.8%→69.6%、65/100 分、9 条符号链接、14 轮对话
- 自曝翻车后一句教训收口：「教训很直接：整包软链会引入无关文件导致报错」；设专节自曝局限（「## 已知局限和前提」「## 代价也很真实」）
- 结论带显式置信度（high/medium/low/unknown；「置信度：中等」）；「可以继续审」≠「已经没问题」
- 留余地只用：往往、大概率、通常、几乎、基本、保守估计、似乎；或时间性限定（「任何 Benchmark 都只是暂时的快照」）；关键预判明说「说实话我也不敢把话说满」。「可能也许或许」式软话不给自己的判断用
- 与 Agent 对峙时写明自己的坚持和胜负（「Agent 试图说服我保留中途 checkpoint，我则一直坚持…」）

## 标点与混排
- 冒号是骨架（引出解释、清单、对话、下定义，篇均 8+）；破折号作解释补刀（全量 141）；顿号并列；分号串联同级（发布文案）
- 引号按文体分（已确认）：公众号文章用弯引号“”（全量 532）；产品叙事、插件文案、自造概念特指用直角「」（87）；篇内不混用；半角引号和半角标点只出现在 AI 稿
- 中英之间加空格（实测 83%，技术文严格执行：「用 AI 写代码」「给 agent 装插件」）
- 数字：度量用阿拉伯数字＋空格＋单位（5.75 亿、87 倍、24 小时）；百分比无空格（94.9%）；修辞性小数目用汉字（三件事、五款、三省六部）；约数用汉字（三、四轮会话）
- 命令、路径、代码、斜杠命令一律反引号原样（`/grill-with-docs`）；链接裸贴
- 感叹号几乎绝迹（87 篇正文自有句约 0 个，35 个全部在 AI 稿和营销稿）；省略号少用（11 个）；情绪用「。。」「？？？」堆叠表达
- 中英混排：永不翻译 Agent、Skill、Harness、Prompt、Token、commit、PR、ADR、QEMU、bitbake、Know-how、worktree、SBOM、RAG、race condition；首次出现加中英对照括注（「ADR（架构决策记录）」「RAG（检索增强生成）」）；「大模型」与 LLM 混用不分主次（已确认）；产品名英文原样；上下文、沙箱、工作流用中文；生硬译法如「AI代理」剔除

## 对话中学到的
- 2026-11-01 建档指示：样本中前期公众号文 AI 味大、后期更好；提炼时剔除明显 AI 味。落实为三层过滤：时间分层、GLM 负样本反推、AI 味剔除清单。GLM「差点意思」稿对比定稿的结论：要浓烈断言、金句加粗、组件齐全、结尾抛互动问；温吞对冲、散文化流水账、「我管这叫」腔等于用户眼中的差点意思
- KAZIKE 稿对比结论：本人版三条新闻并排砸出后接即时身体反应（「我当时就愣了一下」）；比喻服务自己的论点链，不引经据典；已知术语（PMF）不解释；结尾朴素无客套
- 2026-11-01 用户拍板四项：「您/笔者」剔除，一律你/我；「大模型」与 LLM 混用不分主次；正文零 emoji 装饰（功能符号除外）；引号按文体分（公众号“”、产品叙事「」）
